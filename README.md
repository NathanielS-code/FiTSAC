# FiTSAC
FiTSAC stands for Field Theory Symbolic Algebra Calculator. It runs on a custom Graph Theory representation and method, and was created for my Undergrad Thesis.
It can currently solve the Supersymmetric Algebra Closure problem 4D, N=1 interaction-free SUSY theories with simple field index symmetries, although future versions may expand this capability.

# Paper
The pdf in this repository titled "FiTSAC_paper.pdf" explains how to use this code, and provides examples.

# Using the code
Simply run `!pip install git+https://github.com/NathanielS-code/FiTSAC.git` in order to use this repository.

Then to import the relevant functions from either run `import fitsac` or `from fitsac import *`. The examples provided in the arXiv paper use the latter import.

Refer to the paper for the list of functions/classes and how to use them.
